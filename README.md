Proyecto Kafka con Docker

Este proyecto implementa un productor en Python y un consumidor en NestJS que utiliza Express + WebSockets para enviar los mensajes recibidos a una vista en tiempo real. Todo se orquesta con Docker Compose.

🛠 Tecnologías utilizadas

Apache Kafka (broker de mensajería)
Python (productor)
NestJS + Express (API y consumer de Kafka)
WebSockets (emisión de mensajes en tiempo real)
Docker & Docker Compose (orquestación de servicios)
